# راه‌اندازی ظاهر جدید خودمونی

این بسته شامل فایل‌های تغییرکرده با پوشه‌بندی اصلی پروژه است. پوشه‌های `frontend`, `backend`, `admin` و `database` را در ریشهٔ مخزن کپی کنید.

1. در SQL Editor پروژهٔ Supabase فایل `database/migrations/0008_property_cover_photo.sql` را یک بار اجرا کنید. اجرای دوباره نیز مجاز است.
2. فایل‌های داخل ZIP را در مسیرهای هم‌نام مخزن خود جایگزین کنید؛ سپس در GitHub Desktop تغییرات را Commit و Push کنید یا از مسیر همیشگی خود Merge کنید.
3. موفقیت استقرار backend در Render و frontend/admin در Cloudflare Pages را بررسی کنید. اگر استقرار خودکار فعال نبود، استقرار آخرین commit را از داشبورد مربوطه اجرا کنید.
4. سایت را تازه‌سازی کنید و سه آگهی و فلش‌های چپ/راست را آزمایش کنید. آگهی‌ها هر سه ثانیه عوض می‌شوند و پس از آخرین آگهی دوباره از ابتدا ادامه پیدا می‌کنند. نشانگر ماوس روی اسلایدر و حالت کاهش حرکت مرورگر، پخش خودکار را متوقف می‌کند.

اطلاعات آگهی‌ها از وضعیت «آگهی فروش» و آگهی‌های منتشرشده خوانده می‌شود. املاک فروخته‌شده در اسلایدر نیستند. در فرم ثبت و ویرایش ملک، «لینک عکس اصلی آگهی» اختیاری است و باید نشانی مستقیمِ عمومی و امن `https://` داشته باشد؛ بدون آن یک کارت بدون تصویر نمایش داده می‌شود. تصویر بنر اصلی تصویر مفهومی است.

نمودارهای قیمت همان سه گروه قبلی را دارند. کلید و تنظیمات نقشهٔ نشان نیز همچنان از پیکربندی قبلی خوانده می‌شود. این بسته روی سایت زنده منتشر نشده است.
