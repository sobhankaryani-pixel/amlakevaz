# املاک روی نقشهٔ اوز

## پیش از انتشار

1. تغییرات پایگاه داده را به ترتیب اجرا کنید: `0001_initial.sql`، `0002_excel_alignment.sql`، `0003_direct_entry.sql`، `0004_map_locations.sql`. اگر سه مورد اول قبلاً اجرا شده‌اند، تنها `0004` را اجرا کنید. اجرای migrationها روی پایگاه اصلی نیازمند نسخه پشتیبان است.
2. در Google Cloud یک پروژه با Billing فعال بسازید، Maps JavaScript API را فعال کنید و یک API key مخصوص مرورگر بگیرید. برای همان کلید محدودیت Website/HTTP referrer برای `https://evazmelk.ir/*`، `https://www.evazmelk.ir/*` و `https://admin.evazmelk.ir/*` و محدودیت API فقط Maps JavaScript API تنظیم کنید. این دامنه‌ها از تنظیمات فعلی کد خوانده شده‌اند؛ پیش از اعمال، نشانی واقعی سایت و پنل را تطبیق دهید. در صورت استفاده از preview، دامنه preview را نیز اضافه کنید.
3. مقدار `VITE_GOOGLE_MAPS_API_KEY` را در محیط build هر دو برنامه `frontend` و `admin` قرار دهید (مثلاً فایل `.env` در هر پوشه، بدون ثبت در فایل zip). هر برنامه را بعد از افزودن مقدار دوباره build و روی Cloudflare Pages منتشر کنید. بک‌اند را نیز پس از migration منتشر کنید.
4. در فرم «ثبت ملک» یک آگهی آزمایشی زمین و یک خانه ثبت کنید. با لمس نقشه موقعیت را انتخاب کنید. برای ملک موجود از بخش «املاک ثبت‌شده» موقعیت را تعیین یا اصلاح کنید. فقط ملک با وضعیت «آگهی فروش»، قیمت و مختصات در صفحه «املاک روی نقشه» نمایش داده می‌شود. ملک فروخته‌شده یا لغوشده نمایش داده نمی‌شود.

## تجربه کاربر

عنوان بخش در منوی اصلی و موبایل «املاک روی نقشه» است. برچسب قیمت زمین قرمز و خانه سبز است. فیلتر زمین/خانه و کارت جزئیات با کد ملک، نوع، منطقه، متراژ، قیمت و لینک تماس وجود دارد. آدرس خصوصی به سرویس نقشه ارسال نمی‌شود. بدون کلید Google، پیام راه‌اندازی نمایش داده می‌شود. بدون آگهی دارای مختصات، نقشه خالی می‌ماند؛ نمونه ساختگی روی آن قرار نمی‌گیرد.

## وضعیت فعلی

ساخت هر دو برنامه و بررسی نحوی بک‌اند انجام شده است. اتصال واقعی Google Maps و پایگاه داده به دلیل نبود کلید و دسترسی استقرار در این محیط آزمایش نشده است. برای املاک قدیمی، در «املاک ثبت‌شده» روی «تعیین موقعیت» بزنید و نقطه را ذخیره کنید. آگهی‌های قبلی فقط در صورتی روی نقشه دیده می‌شوند که وضعیت انتشارشان در پایگاه داده `published` و `is_public=true` باشد.
