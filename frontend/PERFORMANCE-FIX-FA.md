# اصلاحات بهینه‌سازی فرانت‌اند

این نسخه برای سبک‌ترشدن بارگذاری اولیهٔ سایت آماده شده است.

## تغییرات

- تصویر پس‌زمینهٔ صفحهٔ اصلی از PNG حدود 3 مگابایتی به WebP حدود 63 کیلوبایتی تبدیل شده است.
- لوگوی سایت از PNG حدود 494 کیلوبایتی به WebP حدود 57 کیلوبایتی تبدیل شده است.
- آیکون سایت از PNG حدود 1.36 مگابایتی به WebP حدود 12 کیلوبایتی تبدیل شده است.
- نسخه‌های اصلی تصاویر در `source-originals/` نگه داشته شده‌اند؛ این پوشه داخل خروجی `public` کپی نمی‌شود.
- صفحات نقشه، ثبت ملک و حساب کاربری به‌صورت lazy-load بارگذاری می‌شوند.
- کد React در خروجی build از کد برنامه جدا می‌شود.
- کش HTML غیرفعال شده تا بعد از انتشار نسخهٔ جدید، مرورگر به فایل‌های JS قدیمی ارجاع ندهد؛ فایل‌های hash‌شدهٔ `/assets/` کش بلندمدت دارند.

## انتشار در لیارا

پس از Commit و Push روی main، بک‌اند از اتصال گیت لیارا و سایت و پنل از GitHub Actions منتشر می‌شوند. دستور ساخت محلی: node build-liara.mjs

این بهینه‌سازی‌ها به‌تنهایی تضمین نمی‌کنند اختلال اینترنت همراه اول کاملاً برطرف شود. تنظیمات کش در liara_nginx.conf ساخته می‌شود.
