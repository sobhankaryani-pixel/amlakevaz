# ثبت مستقیم املاک خودمونی

این نسخه فرم ثبت ملک را جایگزین ورود اطلاعات روزمره از اکسل می‌کند. ابتدا migrationهای `0001_initial.sql`، `0002_excel_alignment.sql` و سپس `0003_direct_entry.sql` را در پایگاه داده اجرا کنید. داده‌های پیشین حذف نمی‌شوند. برنامهٔ عمومی، بک‌اند و پنل ادمین مانند نسخهٔ قبلی جداگانه مستقر می‌شوند.

فرم جدید ابتدا آگهی عمومی می‌سازد. پس از فروش، از «املاک ثبت‌شده» همان ملک را معامله‌شده کنید؛ آگهی بسته می‌شود و قیمت و تاریخ قطعی در `app.property_sales` ذخیره می‌شود. برآوردهای دستی ماهانه در جدولی جدا از معاملات ثبت می‌شوند. نمودارها از یکی از این دو منبع به انتخاب بازدیدکننده استفاده می‌کنند. آگهی‌های قدیمی حذف نمی‌شوند.

## فرم بر اساس نوع ملک

قبل از انتشار این تغییر، `database/migrations/0005_property_type_fields.sql` را یک بار در پایگاه داده اجرا کنید. این تغییر ستون‌های جدید را اضافه می‌کند و داده‌های قبلی را حذف نمی‌کند. سپس بک‌اند API و هر دو پروژهٔ Pages (پنل ادمین و سایت عمومی) را با نسخهٔ جدید منتشر کنید. فقط انتشار فایل‌های پنل، داده‌های جدید را ذخیره نخواهد کرد.

در «ثبت ملک» یکی از هفت نوع زمین، خانهٔ ویلایی، آپارتمان، مسکن مهر، مسکن ملی، مغازه یا باغ شهری انتخاب می‌شود. زمین کاربری مسکونی یا تجاری دارد. مسکن مهر بخش محلی/فرهنگیان، موقعیت طبقهٔ بالا/پایین و قیمت دارد. خانهٔ ویلایی نوع نوساز/کلنگی، متراژ زمین، زیربنا، خواب و تعداد طبقه دارد. مشخصات هر نوع در فرم همان نوع و در جزئیات آگهی نقشه نشان داده می‌شوند. کد ملک و منطقه برای تمام نوع‌ها لازم هستند؛ انتخاب موقعیت روی نقشه اختیاری است. تغییر نوع در فرم، مشخصات مخصوص نوع قبلی را پاک می‌کند، ولی کد ملک، منطقه، قیمت، آدرس و موقعیت را حفظ می‌کند.

نوع‌های مغازه و باغ شهری و مسکن مهر/ملی به داده‌های مرجع migration `0003_direct_entry.sql` وابسته هستند. `0005` را فقط پس از `0003` و `0004` اجرا کنید. بک‌اند فعلی روی Cloudflare Pages منتشر نمی‌شود؛ باید سرویس backend متصل به Worker `api.evazmelk.ir` هم نسخهٔ جدید را دریافت کند. تا پیش از انتشار هم‌زمان، فرم تازه را برای ثبت ملک استفاده نکنید.

پیش از فعال‌سازی، migration را در Supabase اجرا کنید و با حساب مدیر، ثبت هر سه وضعیت و یک بازهٔ شاخص را روی پایگاه آزمایشی بررسی کنید. API روی `https://api.evazmelk.ir` تنظیم شده است.

## انتشار یک‌جای فرم و نمودارها

این ZIP جایگزین بستهٔ قبلی فرم انواع ملک است؛ نیازی به دریافت جداگانهٔ آن نیست. پس از کپی فایل‌های بسته به ریشهٔ مخزن، در SQL Editor سوپابیس ابتدا `database/migrations/0005_property_type_fields.sql` و بعد `database/migrations/0006_market_charts.sql` را اجرا کنید. پیش‌نیازهای قبلی `0001` تا `0004` باید روی همین پایگاه داده اجرا شده باشند. سپس نسخهٔ جدید بک‌اند FastAPI متصل به Worker و هر دو پروژهٔ Cloudflare Pages (admin و frontend) را منتشر کنید. تنها انتشار GitHub و Pages برای فعال‌شدن API جدید کافی نیست.

پنل «قیمت شاخص» برای زمین مسکونی، زمین تجاری، خانهٔ ویلایی نوساز، آپارتمان و مسکن مهر قیمت ماهانه ثبت می‌کند. زمین بر اساس منطقه؛ خانه، آپارتمان و مهر در نمودار فعلی برای کل اوز هستند. برآورد دستی همان عدد واردشده است؛ برای معاملات، میانهٔ قیمت قطعی همان ماه محاسبه می‌شود. زمین بر حسب هر متر زمین، خانه و آپارتمان بر حسب هر متر زیربنا، و مهر بر حسب قیمت کل واحد هستند. خانهٔ کلنگی وارد نمودار نوساز نمی‌شود. ماه بدون داده خالی می‌ماند. شاخص کل ترکیبی فعلاً تعریف نشده است.
