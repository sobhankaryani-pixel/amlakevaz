# بستهٔ بازطراحی صفحهٔ اصلی املاک خودمونی اوز

این بسته بر اساس طرح سوم انتخاب‌شده آماده شده است. هدف، نزدیک‌کردن صفحهٔ اول سایت به ماکت انتخاب‌شده است، بدون حذف مسیرهای فعلی ثبت ملک، حساب کاربری، نقشه و شاخص قیمت.

## تغییرات

- نوار تماس جمع‌وجور سرمه‌ای با لینک‌های «دربارهٔ ما»، «تماس با ما» و «افزودن آگهی».
- هیروی تصویری با پنل شیشه‌ای سمت راست و دکمهٔ «مشاهدهٔ آگهی‌ها».
- شاخص قیمت جمع‌وجور با سه کارت و درصد تغییر خودکار بر اساس دو دورهٔ آخرِ موجود در API؛ وقتی دو دورهٔ معتبر وجود نداشته باشد «—» نمایش داده می‌شود و درصد ساختگی تولید نمی‌شود.
- بخش «املاک ویژه و آخرین آگهی‌ها» با چهار کارت قابل ویرایش از پنل مدیریت.
- بخش جست‌وجوی سریع منطقه و نقشهٔ نمادین؛ نقشهٔ این بخش تزئینی/راهنماست و برای موقعیت دقیق، دکمهٔ نقشه صفحهٔ نقشهٔ واقعی سایت را باز می‌کند.
- پنل مدیریت: بخش «تبلیغات صفحهٔ اصلی» برای ویرایش عنوان، توضیح، برچسب، عکس، متن دکمه، مقصد، ترتیب و فعال/غیرفعال‌بودن هر کارت.
- چهار عکس اولیه صرفاً تصاویر نمادین هستند؛ این کارت‌ها قیمت یا مشخصات معاملهٔ واقعی ادعا نمی‌کنند.

## فایل‌هایی که باید در پروژهٔ اصلی ادغام شوند

- `frontend/src/App.tsx` (جایگزین فایل فعلی)
- `frontend/src/styles.css` (جایگزین فایل فعلی)
- `frontend/src/PriceDashboard.tsx` (جایگزین فایل فعلی)
- پوشهٔ `frontend/public/homepage-promos/` (چهار تصویر اولیه)
- `admin/src/App.tsx` (جایگزین فایل فعلی؛ منوی مدیریت تبلیغات و CRM را اضافه می‌کند)
- `admin/src/HomepagePromotions.tsx` (فایل جدید)
- `admin/src/HomepagePromotions.css` (فایل جدید)
- `admin/src/CRM.tsx` و `admin/src/CRM.css` (برای سازگاری بخش مخاطبان و پیامک که در منوی مدیریت این نسخه استفاده می‌شود)
- `backend/app/main.py` (جایگزین فایل فعلی؛ API عمومی و مدیریت کارت‌ها را اضافه می‌کند)
- `backend/app/crm.py` (ماژول CRM مورد استفادهٔ پنل مدیریت)
- `database/migrations/0012_homepage_promotions.sql` (مهاجرت جدید)

**کل پروژه را با این بسته جایگزین نکنید.** این ZIP فقط فایل‌های مرتبط با تغییرات را دارد؛ فایل‌های دیگر پروژه باید باقی بمانند.

## ترتیب انتشار

1. از پروژهٔ فعلی و دیتابیس نسخهٔ پشتیبان داشته باشید.
2. فایل `database/migrations/0012_homepage_promotions.sql` را در SQL Editor سوپابیس اجرا کنید. این جدول چهار کارت اولیه را نیز ایجاد می‌کند. اجرای دوبارهٔ اسکریپت، کارت‌های دارای همان `slug` را تکرار نمی‌کند.
3. فایل‌های بالا را در مسیرهای متناظر پروژه کپی و جایگزین کنید.
4. در GitHub Desktop تغییرات را مرور کنید؛ فقط بعد از اطمینان از نبود فایل محرمانه یا تغییر ناخواسته Commit و Push کنید.
5. منتظر Deploy موفق بک‌اند Render و فرانت‌اند/پنل Cloudflare Pages بمانید.
6. در پنل مدیریت وارد بخش «تبلیغات صفحهٔ اصلی» شوید. چهار کارت اولیه باید نمایش داده شوند.

## تغییر تصویر در پنل مدیریت

فیلد عکس URL عمومی `https://...` یا مسیر محلی مانند `/homepage-promos/villa.webp` می‌پذیرد. برای عکس تازه می‌توان URL عمومی تصویر را وارد کرد. برای میزبانی عکس داخل خود سایت، فایل را در `frontend/public/homepage-promos/` قرار دهید، فرانت‌اند را دوباره منتشر کنید و مسیر `/homepage-promos/نام-فایل.webp` را در پنل ثبت کنید.
