# بستهٔ الحاقی بازطراحی صفحهٔ اصلی املاک خودمونی — طرح سوم

این بسته برای ادغام در پروژهٔ اصلی است؛ **کل پروژه نیست** و نباید پوشه‌های اصلی پروژه را با همین بسته جایگزین کنید.

## تغییرات صفحهٔ اصلی

- هدر تک‌ردیفه و سرمه‌ای با لوگو در راست، منوی کامل در یک ردیف و دکمه‌های جستجو/ورود/حالت نمایش در سمت چپ.
- در صفحهٔ اصلی، «آگهی‌ها» با خط طلایی به‌عنوان گزینهٔ فعال مشخص می‌شود؛ در صفحه‌های دیگر گزینهٔ همان صفحه فعال است.
- بنر تصویری با پنل شیشه‌ای در سمت راست، تیتر دوخطی «بازار املاک اوز / شفاف‌تر از همیشه» و دکمهٔ «مشاهدهٔ آگهی‌ها».
- ردیف چهار مزیت زیر بنر.
- شاخص قیمت فشرده با سه کارت و درصد تغییر محاسبه‌شده از دو دورهٔ آخر دادهٔ معتبر. رشد سبز و کاهش/ثبات قرمز است؛ در نبود دو دورهٔ معتبر، به‌جای عدد ساختگی «—» نمایش داده می‌شود.
- شاخص قیمت هنگام برگشت به تب و هر ۶۰ ثانیه دوباره دریافت می‌شود تا دادهٔ تازه بدون بارگذاری دستی صفحه هم نمایش داده شود.
- چهار کارت تصویری اولیه در بخش «املاک ویژه و آخرین آگهی‌ها»؛ تصاویر و متن‌ها نمونه و قابل‌ویرایش‌اند، نه آگهی واقعی.
- پنل مدیریت: بخش «تبلیغات صفحهٔ اصلی» برای ویرایش عنوان، توضیح، برچسب، عکس، متن دکمه، مقصد، ترتیب و فعال/غیرفعال‌کردن هر کارت.
- بخش جست‌وجوی سریع منطقه با تصویرهای نمادین و نقشهٔ راهنمای نمادین؛ برای موقعیت واقعی، دکمهٔ نقشه صفحهٔ نقشهٔ اصلی سایت را باز می‌کند.
- فرم ثبت داوطلبانهٔ مخاطب و مسیر CRM حفظ شده‌اند؛ کانال‌های پیامکی/واتساپی فقط بر اساس رضایت ثبت‌شده نگهداری می‌شوند.

## روش ادغام و انتشار

1. در پوشهٔ ریشهٔ پروژهٔ اصلی، محتویات این بسته را با همان ساختار پوشه‌ها کپی و فایل‌های هم‌نام را جایگزین کنید؛ **کل پروژه را حذف نکنید**.
2. اگر مهاجرت `0011_public_contact_capture.sql` قبلاً در Supabase با موفقیت اجرا شده، نیازی به اجرای مجدد آن نیست. اگر اجرا نشده، آن را قبل از 0012 اجرا کنید.
3. اگر `0012_homepage_promotions.sql` قبلاً با موفقیت اجرا شده، اجرای دوباره لازم نیست. در غیر این صورت آن را در SQL Editor سوپابیس اجرا کنید تا جدول و چهار کارت اولیه ساخته شوند.
4. در GitHub Desktop فایل‌های تغییرکرده را بررسی کنید، سپس Commit و Push انجام دهید. پس از آن وضعیت Deploy در Render و Cloudflare Pages را جداگانه بررسی کنید.
5. پس از Deploy، صفحهٔ اصلی، سه کارت شاخص قیمت، چهار کارت تبلیغاتی و بخش جدید پنل مدیریت را تست کنید.

## نکات مهم

- این بسته به مخزن یا دامنهٔ زنده دسترسی مستقیم ندارد؛ بنابراین **انتشار روی سایت انجام نشده** و باید از طریق GitHub/Render/Cloudflare خودتان انجام شود.
- تصاویر چهار کارت تبلیغاتی و نقشه صرفاً نمادین‌اند. قیمت، درصد تغییرات یا مشخصات معاملهٔ ساختگی وارد نشده است.
- فیلد عکس در پنل مدیریت URL عمومی HTTPS یا مسیر محلی سایت می‌پذیرد؛ بارگذاری مستقیم فایل از رایانه در این نسخه اضافه نشده است.
- ساخت کامل Vite با npm در این محیط ممکن نشد، چون دریافت وابستگی‌ها از npm registry در دسترس نبود. بررسی نحوی TSX و Python انجام شده است؛ پیش از انتشار نهایی، Deploy Preview یا build محلی پروژه را بررسی کنید.
